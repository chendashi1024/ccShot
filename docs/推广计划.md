# CcShot · 推广计划

> 目标：拿 GitHub star。以下是讨论中整理的思路，具体规则发帖前要再去各平台核对（待验证）。

## 1. 核心思路：集中火力，冲 Trending

- GitHub Trending 是按 **star 增长速度** 排的，不是按总数。所以要**同一时间在所有渠道一起发**，让 star 在短时间内集中涨，冲上 Trending，再带来更多自然流量。
- 发布前准备好：
  - README：第一句话讲清楚用途（名字看不出功能，这句很重要）；配**演示 GIF**，展示三个亮点：截完直接选字、一键问 AI、一键美化成 1920×1080。
  - 首次打开图解（未签名，系统会拦）：系统设置 → 隐私与安全性 → 仍要打开，或 `xattr -dr com.apple.quarantine /Applications/CcShot.app`。
  - GitHub Releases 里的 .dmg / .zip 能直接下载使用。
  - 中英文 README（海外渠道看英文）。

## 2. 渠道

| 渠道 | 受众 | 注意事项 |
|---|---|---|
| Show HN（Hacker News） | 海外开发者 | 标题用 "Show HN: …"，讲清楚开源、原生、自带 Key |
| r/macapps（Reddit） | 海外 Mac 用户 | 规则严格：标题要带 **[OS]** 标签（开源）；对账号 karma 有要求；要**说明是否用了 AI 开发**；**每 30 天只能发 1 条推广帖**。发帖前重新读一遍版规 |
| V2EX | 国内程序员 | 发在合适的节点（如分享创造），真诚介绍，回复评论 |
| LINUX DO | 国内开发者社区 | 同上 |
| 少数派 | 国内效率工具 / Mac 用户 | 适合写一篇使用介绍或投稿 |
| 短视频平台 | 更广的中文用户 | 录 30 秒内的演示：按 F1 → 截图 → 直接选字 → 一键问 DeepSeek |

## 3. 节奏建议

1. 发布前：README、GIF、Release 都准备好；在小范围先让几个人试用，修掉明显 bug。
2. 发布当天：各渠道集中发，及时回复评论和 issue。
3. 发布后：根据反馈快速出小版本，在 Release 说明里写清楚升级后可能要重新授权屏幕录制。

## 4. 卖点话术（统一口径）

- 中文：像 Snipaste 一样快的 Mac 截图工具，截完文字直接能选，一键问你自己的 AI（默认 DeepSeek）。开源、免费、原生。
- 英文（草稿）：A fast, native, open-source Mac screenshot tool — select text right on your screenshot and ask your own AI with one key (BYOK).
