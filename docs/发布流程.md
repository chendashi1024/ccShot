# ccShot 发布流程

## 版本和更新

版本标签采用 `v主版本.次版本.修订号`。破坏性变更升主版本，兼容的新功能升次版本，兼容修复升修订号。公开预览版在 GitHub Releases 标记为预发行。普通用户从官网或 Releases 下载新版，退出 ccShot 后替换「应用程序」里的旧版。当前通过手动下载更新。

## 发布 Mac 安装包

1. 将 CHANGELOG 的本次变化归到版本小节，同步官网推荐下载的版本与链接，记录系统、架构和已知问题。
2. 从已提交的 main 运行 `bash app/check.sh --core-only`。检查真实样本与本次改动有关的界面，并如实记录全量检查或真实设备未通过的项目。
3. 运行 `bash app/package-release.sh 0.1.0`，参数改为本次版本。输出包含 Apple Silicon 的 DMG 和 SHA-256 校验文件。
4. 只读挂载 DMG，核对 App 版本、架构、签名、拖入「应用程序」入口和首启体验。发行脚本当前生成临时签名包，未经 Apple 公证。
5. 在同一源码提交打 `v0.1.0` 标签，将 DMG 与校验文件上传到对应的 GitHub Release。发布说明列出变化、安装要求、升级方式和已知问题。
6. 在浏览器匿名打开发布页并下载安装包，核对哈希。官网更新由已授权部署智能体发布，验收首页和真实下载链路。

已发布文件如需修正，用新版本和新标签交付，避免同名安装包对应不同内容。
