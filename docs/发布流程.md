# ccShot 发布流程

## 版本和更新

版本标签采用 `v主版本.次版本.修订号`。破坏性变更升主版本，兼容的新功能升次版本，兼容修复升修订号。公开预览版在 GitHub Releases 标记为预发行。普通用户从官网或 Releases 下载新版，退出 ccShot 后替换「应用程序」里的旧版。当前通过手动下载更新。

## 发布 Mac 安装包

1. 将 CHANGELOG 的本次变化归到版本小节，同步官网推荐下载的版本与链接，记录系统、架构和已知问题。
2. 从已提交的 main 运行 `bash app/check.sh --core-only`。检查真实样本与本次改动有关的界面，并如实记录全量检查或真实设备未通过的项目。
3. 运行 `bash app/package-release.sh 0.1.0`，参数改为本次版本。输出包含 Apple Silicon 的 DMG 和 SHA-256 校验文件。
4. 只读挂载 DMG，核对 App 版本、架构、签名、拖入「应用程序」入口和首启体验。发行脚本当前生成临时签名包，未经 Apple 公证。
5. 在同一源码提交打 `v0.1.0` 标签，将 DMG 与校验文件上传到对应的 GitHub Release。发布说明列出变化、安装要求、[升级步骤](#release-升级说明)和已知问题。
6. 在浏览器匿名打开发布页并下载安装包，核对哈希。官网更新由已授权部署智能体发布，验收首页和真实下载链路。

已发布文件如需修正，用新版本和新标签交付，避免同名安装包对应不同内容。

## Release 升级说明

后续发布复制下面的升级段落。正常路径先写拖拽覆盖和默认快捷键，旧授权清理放在折叠区。

### 升级安装

1. 从下方 Assets 下载新版 DMG。在菜单栏的 ccShot 菜单中选择「退出 ccShot」。
2. 打开 DMG，把 **ccShot.app** 拖进「应用程序」，选择「替换」。
3. 从「应用程序」打开 ccShot。若系统阻止打开，核对安装包的 SHA-256 后，到「系统设置 → 隐私与安全性」选择「仍要打开」。按 **F1** 截图。改过快捷键的话，继续用原来的设置，也可以在「ccShot 菜单 → 设置… → 截图快捷键」重新设置。如果 F1 调节亮度，试按 **Fn + F1**。

<details>
<summary>仅在升级后反复提示截图权限、系统设置里已有 ccShot 时处理</summary>

1. 从菜单栏退出 ccShot。
2. 打开「终端」，运行以下命令，清掉 ccShot 的旧屏幕录制授权记录。

```bash
tccutil reset ScreenCapture com.ccshot.dev
```

3. 从「应用程序」重新打开 ccShot，用菜单栏的「区域截图」触发授权，点击「请求授权」。在「系统设置 → 隐私与安全性 → 屏幕与系统音频录制」允许 ccShot，然后退出并重新打开 App。

</details>
