# ccShot 发布流程

## 版本和更新

macOS 和 Windows 使用同一个产品版本号，由仓库根目录的 [VERSION](../VERSION) 提供。版本标签采用 `v主版本.次版本.修订号`。破坏性变更升主版本，兼容的新功能升次版本，兼容修复升修订号。公开预览版在 GitHub Releases 标记为预发行。当前通过手动下载更新。

## 双平台发布

1. 把本次改动合入 `main`，在 [VERSION](../VERSION) 更新版本号，在 [CHANGELOG](../CHANGELOG.md) 记录两端变化、发布日期和已知问题。更新 README 下载地址、`website/src/index.js` 的版本及 `website/public/llms.txt` 的发行信息。官网模板从 `VERSION` 生成双平台地址与安装说明。按[官网说明](../website/README.md#发布源)构建首页、重建清单并运行测试。
2. 推送 `main` 的版本改动会触发 [macOS 构建](https://github.com/chendashi1024/ccShot/actions/workflows/macos.yml)和 [Windows 构建与桌面验证](https://github.com/chendashi1024/ccShot/actions/workflows/windows.yml)。需要重试时在 GitHub Actions 从 `main` 运行对应流程，并在下载前核对运行记录的源码提交。
3. 两端检查通过后，下载各自的产物 `ccshot-macos-arm64` 和 `ccshot-windows-x64`。Mac 产物中的 DMG 和校验文件在同一个子目录。Windows 产物有 ZIP 和同名 `.sha256` 文件。也可从同一提交本地打包，命令见下方。整个版本只上传同一批已验收的包，GitHub 和官网下载用同一份文件。
4. 用 `shasum -a 256 -c` 核对两份安装包。只读挂载 DMG，核对 App 内版本、源码提交、ARM64、临时签名和「应用程序」入口，并实测本次改动相关的截图操作。解压 Windows ZIP，核对 `BUILD-INFO.txt`、程序版本、运行库和模型。参考 Windows 桌面检查的截图、选字、剪贴板、离线验证和正式 ZIP 启动结果，逐项记录验收范围。
5. 在该提交上打与 `VERSION` 一致的 `v` 标签。创建 GitHub Release 草稿，上传两个包与各自的 `.sha256`，校验四个附件后发布。发布说明包含两端变化、系统要求和[升级说明](#release-升级说明)。匿名从 Release 下载并核对哈希。
6. 把同一批四个文件上传到 `ccshot-downloads`。从 `download.ccshot.app` 独立下载并核对两个包的 SHA-256。两端文件可用后，按[官网发布说明](../website/README.md#从本机发布)切换现有 Worker，再检查正式首页、双平台下载、校验文件和安装说明。若官网校验失败，将 Worker 流量切回发布前的版本并复查入口。
7. 在项目私有发布目录记录源码提交、GitHub Release、两端哈希与验收结果、正式 Worker 版本和回滚版本。已发布文件需要修正时，递增版本号及标签，再走一次发布流程。

本地构建入口如下。发行包应基于干净的发布提交构建。

```bash
bash app/check.sh --core-only
bash app/package-release.sh
bash windows/tools/fetch-models.sh mobile
bash windows/tools/package.sh
```

Windows 构建依赖见 [Windows 开发说明](../windows/README.md#构建与运行)。本地 Windows 打包生成的 `SHA256SUMS.txt` 可复制为对应的 `ccShot-<版本号>-windows-x64.zip.sha256`，两者的校验内容一致。

## Release 升级说明

后续发布复制下面的升级段落。正常路径先写拖拽覆盖和默认快捷键，旧授权清理放在折叠区。

### 升级安装

1. 从下方 Assets 下载新版 DMG。在菜单栏的 ccShot 菜单中选择「退出 ccShot」。
2. 打开 DMG，把 **ccShot.app** 拖进「应用程序」，选择「替换」。
3. 从「应用程序」打开 ccShot。若系统阻止打开，核对安装包的 SHA-256 后，到「系统设置 → 隐私与安全性」选择「仍要打开」。按 **F1** 截图。改过快捷键的话，继续用原来的设置，也可以在「ccShot 菜单 → 设置… → 截图快捷键」重新设置。如果 F1 调节亮度，试按 **Fn + F1**。

<details>
<summary>仅在升级后反复提示截图权限、系统设置里已有 ccShot 时处理</summary>

1. 从菜单栏退出 ccShot。
2. 打开「终端」，运行以下命令，清掉 ccShot 的旧屏幕录制授权记录。

```bash
tccutil reset ScreenCapture com.ccshot.dev
```

3. 从「应用程序」重新打开 ccShot，用菜单栏的「区域截图」触发授权，点击「请求授权」。在「系统设置 → 隐私与安全性 → 屏幕与系统音频录制」允许 ccShot，然后退出并重新打开 App。

</details>
