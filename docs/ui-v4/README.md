## 已确认的交互规则

- ⌘C：有选中文字时复制文字，否则复制图片，继续保留截图界面。
- 完成/回车：采用同一复制目标规则，成功复制后结束截图；失败时保留现场。
- 保存：保存图片文件；钉住：转为桌面浮窗。
- 主按钮固定“完成”，悬停提示具体复制对象及回车快捷键；去掉底部常驻快捷键说明。
- 产品提供经过设计的固定默认样式：箭头采用两条线组成的开口箭头尖、圆润线端和绿色，线宽、框角等保持统一。不给用户暴露“空心箭头”、颜色、粗细和样式选择面板。

本轮只落实设计预览，正式 App 的系统快捷键与导出行为待原生接入验证。
