# CcShot 原地编辑实施计划

> 主代理使用原生工具串行实施；用户已明确继续执行、默认直接完成，不另设审批。执行采用 superpowers:executing-plans 的逐项核验方式，遵守项目按风险定向检查与精确提交要求。

**目标：** 按 GOALS 第1.1节把真实截图编辑保留在原选区，工具与参数就近浮动；不能以原独立大窗口替代还原。

**架构：** 复用 AnnotationDocument、AnnotationCanvas、VisionKit 与现有安全合成。ImageWindow 增加截图原位呈现；全屏背景只用于显示，文档和输出始终仅持有选区图。普通图片与钉图路径保留，逐项对齐对应目标。

**技术：** 现有 Swift/AppKit、macOS14 构建目标，不引入依赖。

**依据：** GOALS.md#ui-contract；docs/UI参考与设计.md#native-ui-gap；docs/ui-v3/ 五场景。

## 必须守住

- 所有输出、注释与提交中文；不安装、不增加权限、不公开发布，不覆盖其他 WIP。
- 原位与原尺寸、直接选字、标注编辑、撤销、样式和安全输出均保留。
- 首排常用工具、图标加必要中文、自动参数；字号24、B、单底色、集中色板和弯箭头手势保留。
- 截图背景绝不进入剪贴板、保存和钉图文档；选区调整期间不得交付旧图或旧文字。
- 调整选区只在未标注且未输入时允许；屏幕变动后保留当前图，拒绝用过期几何重新裁图。

## 重点复查

- 小选区、整屏及靠近屏边，工具条和参数避让且不改变截图比例。

- 钉图副本、设置开关及取消保存不损坏原文档。
