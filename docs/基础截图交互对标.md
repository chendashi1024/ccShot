# CcShot 基础截图交互逐项对标

日期：2026-11-03。范围：Mac/PC 核心截图体验。性质：本轮对标结论与修订建议，新增模块建议尚未实施；观众复评中的既有交互修正见末节，不能作为全部验收通过记录。

**原则：少放高级选项，但保留完整的基本操作。** 工具的画法、选中与修改、快捷键习惯、输出结果必须可靠；布局、品牌色、文案和高级功能数量可以不同。不存在一家软件的全部交互都必须照搬；参考之间有冲突时，优先 Mac 平台习惯和 CcShot 已确定的“直接选字”。

本轮读取官方说明，查看 PixPin 的文字/矩形工具栏原图和 CleanShot 的调色板原图；没有安装或亲手操作这些竞品。官网存在的功能不代表本轮验证了它的性能、所有状态或默认设置。Windows 文档中的 Ctrl 不直接照搬成 Mac 按键。Snipaste 通用入门页部分二次编辑说明较旧，不作为当前版本不能编辑的依据。

## 修订顺序与验收例子

**第一组：已确认的核心操作差距，下一轮优先处理。**

1. 打通框选后的常用工具与输出：框选 → 点箭头 → 画 → 复制，不出现额外“完成”中转；保存/钉住同样直接。
2. 补矩形/椭圆、直线的鼠标入口，补 Shift 正方形/正圆。新用户不看快捷键表也能圈一个圆、画一条线。
3. 保留文字参数这轮改法，核对输入中切工具、改参数、输出与中文候选的连续操作。不能为了省一步损坏输入事务。

**第二组：先修已有操作与精简重复控件。** 已显示的控制点必须能直接拖动；选字提示必须符合当前模式；粗细保留三档图形预设和一个数值输入，取消重复滑块。这些优先于新增大模块。
