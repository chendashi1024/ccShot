# 基础标注交互排查 · 2026-11-09

## 用户反馈与修复范围

本轮依据用户反馈检查两条实际任务链：画完标注后撤销；画完框或箭头后继续调整。扩大检查到重新选择、端点、缩放、删除、样式、文字输入、选字、连续绘制和钉图。范围为 macOS 桌面原生 App。

此前只测 `AnnotationDocument.undo()` 并不能证明键盘入口可用；只在填充框上检查拖动，也覆盖不到空心框内部。新增检查从原生窗口派发鼠标和键盘事件，检查最终对象数量、位置、历史及输入内容。

## 同类工具依据

没有一份适用于所有截图工具的统一交互规范，但成熟产品有可核实的共同行为。本轮只参考官方说明，没有复制竞品代码。

| 官方来源 | 可核实行为 | ccShot 采用方式 |
| --- | --- | --- |
| [Shottr 入门](https://shottr.cc/kb/startguide) | 已有标注可再次选择、移动、缩放和修改属性 | 保留标注对象，直接调整；选择工具可选各种对象 |
| [PixPin 标注基础](https://pixpin.cn/docs/annotation/basics) | 同类工具可二次编辑；选中时改当前对象，取消选中再为新标注设置样式 | 同类绘图工具可以重选旧对象；不再自动修改最后一条未选中的对象 |
| [Snipaste 官方更新记录](https://www.snipaste.com/download.html) | 撤销重做；Shift 拖动沿水平或垂直方向移动；笔刷连续绘制需避免意外移动 | 几何工具与笔刷分开处理，补齐 Shift 轴向移动 |
| [Apple 撤销与重做](https://support.apple.com/en-ie/guide/numbers/tan267caaf5a/mac) | Mac 通常用 ⌘Z / ⌘⇧Z | 保留系统习惯，额外兼容用户提到的 Ctrl 组合键 |

Option 在旧图形上强制新画、框内原图文字优先选字，是本项目为解决操作冲突采用的规则，不声称所有竞品一致。

## 根因与最终规则

| 问题 | 原因 | 修复后 |
| --- | --- | --- |
| Ctrl+Z 无反应，快捷键受焦点影响 | 画布拒绝 Control/Command，Command 历史只依赖菜单；窗口缺少统一入口 | 窗口统一处理 ⌘Z、⌘⇧Z、Ctrl+Z、Ctrl+Shift+Z、Ctrl+Y |
| 空心框内拖动新建框 | 命中只接受边线 | 框内部可以移动，已有笔画优先，避免大框抢走小对象 |
| 重新切回工具后难以移动旧对象 | 绘图工具只检查当前已选对象 | 同类工具可以重选旧对象；切换其他工具仍能在框内画图 |
| 箭头控制点不直接可用 | 精简模式隐藏并禁用端点和弯曲控制点 | 完成绘制即显示控制点；端点改起止位置，中点改弯曲，线身平移 |
| 未选中调色却改变旧对象 | 自动回退到最后一条同类对象 | 无选择只更新下一次绘制样式，有选择才修改当前对象 |
| 拖动时删除造成历史混乱 | 已提交对象与拖动草稿可同时被不同操作修改 | 拖动中屏蔽删除、微调和完成；撤销先取消本次拖动；Esc 保留原对象 |
| 文字撤销状态不正确 | 菜单启用状态只看画布历史 | 输入框独立使用文字历史，中文候选期间不改画布；普通参数输入框保留系统处理 |
| 钉图查看态可误改历史 | 撤销入口未检查编辑状态 | 只有进入钉图编辑态才允许修改标注 |
| 基础辅助操作不完整 | 缺少 Shift 正形和轴向移动 | 补齐 Shift 正方形/正圆与轴向拖动，保留方向键 1/10 像素微调 |

画笔、遮挡、高亮、连续编号保持连续绘制；需要移动时切到选择工具。空白处继续画，Option 拖动可在同类旧图形上另画。选择工具下，未选中空心框内的原图文字仍可拖选；已经选中的框优先移动。

## 验证与证据

- `bash app/check.sh` 完整通过：核心几何/像素/偏好检查，以及标注 54 项、遮挡与安全选字 37 项、文字 24 项、原位编辑 46 项、窗口原位 6 项、钉图 29 项。
- `bash app/check-interactions.sh` 的 38 项原生事件检查全部通过，包括框内拖动、跨工具绘制、快捷键、焦点、文字与候选保护、历史、微调、边界、重叠图形、原图选字和钉图查看态。结果写入 `app/build/interaction-tests.json`。
- 初版新增用例在修复前有 14 项失败；修复后通过。扩展检查进一步复现并修复了框内切换箭头工具被旧框拦截的问题。
- 历史标注检查的九个失败来自浮点坐标尾差，例如高度 `140.00000000000003` 与 `140` 的直接相等比较。改为小于百万分之一像素的误差判断，继续检查对象身份、数量、属性和撤销恢复；另一项字号断言错误写死旧默认值，改为与该测试对象原字号比较。没有通过修改产品坐标或删除检查掩盖失败。
- 已检查[原生界面渲染](../app/previews/interaction-controls-2026-11-09.png)：精简工具栏、三色与曲线选项，以及画完后可见的箭头控制点；这是 AppKit 窗口的自制样本，不是设计稿。

桌面控制工具连续读取应用超时，本轮未完成真人式鼠标键盘复核。事件测试不等于实体键盘验证；系统中文候选由原生文本输入协议模拟，未声称完成真实拼音输入法或混合缩放多屏验收。公开下载仍为原发布版，本次代码修复不等于已经发布新的 GitHub Release。
