## 这次具体简化了什么

| 场景 | 当前候选 | 原因 |
|---|---|---|
| 截图后 | 箭头、画框、文字、画笔、遮挡、高亮、序号在前；选择、撤销重做与输出同排 | 常用功能截完直接可点，不能为减少按钮而多走一步。 |
| 标注 | 直接点工具并画，再直接复制、保存或钉住 | 不设「标注」总入口，也不要求先点「完成」才能输出。 |
| 样式 | 点工具即在其下方显示参数；线型、粗细、箭头头部、填充用图形预览，字号用数字 | 不再多点样式按钮，直接看见可选效果；主要操作保留中文，图形有中文提示和可访问名称。 |
| 选字 | 截完直接选；已有「复制」变为「复制文字」 | 不加 OCR 开关，不再弹第二条操作栏。 |
| 钉图 | 内容为主；标注、复制、关闭按悬停或聚焦出现 | 选字直接拖选，缩放通过滚轮和菜单/键盘路径，不重复放按钮。画板显示的是操作栏显现态。 |
| 设置 | 截图快捷键、保存位置两项 | 默认值能解决的事不交给新用户；登录启动、AI 配置等高级项后续再排。 |

撤销重做在同排提供图标，同时保留快捷键；对象编辑、必要权限和错误反馈不删。Fn 提示只在相关快捷键引导出现；快捷键冲突、目录错误、保存失败在实际发生位置说明。不能用极简为由隐藏失败、削弱遮挡安全或让动作不可发现。

当前先做截图、选字、常用标注、复制/保存和钉图；AI、美化、低频扩展及高级设置暂不进入默认界面，常用标注不能因此被隐藏。原生已有实现保留，本轮同步修改 ImageWindow 的参数显示和控件布局。试稿中的遮挡演示不代表原 #18 已全部验收；原生状态按对应验证记录评定。

## 与参考软件的差异

第二版沿用了较多紧凑图标分组和蓝色选中，本轮改成暖白、墨灰与深青绿；常用标注有中文名称，与输出在同一条工具栏清楚分组，设置没有分类侧栏。差异来自结构、优先级和用词，而不只是换颜色。原位置截图、直接选字、轻量钉图仍是 ccShot 自身体验重点。

第三版自有参数：40pt 操作区、14–16pt 控件文字、8–12pt 圆角、系统字体。它们是候选值，不是竞品测量数据。辅助文字只在帮助操作或判断时出现；预览外框中的“设计演示”及限制说明属于评审页，不放入 App 日常工具栏。

## 原型能力与验证边界

已编写五画面切换、七种示例标记和示例撤销重做、自动样式面板与图形选项、颜色/粗细/字号、固定示例文字复制、示例 PNG 保存/复制。图片输出只取示例内容层，不带工具栏与选字高亮；复制/下载失败明确反馈。设置只演示值的变化，不修改系统。没有自由绘制、任意拖选 OCR、真实窗口置顶或系统设置实现。

SVG/HTML 由同一源生成。PNG 使用 macOS Quick Look 渲染；逐张查看画面与控件，不把导出图算浏览器点击或原生体验验收。当前浏览器工具返回 **Local browser use is disabled in Work settings**，未换通道绕过；交互仅完成静态检查，点击、剪贴板和下载仍待浏览器验证。原生自动显示和图形选项已通过 AppKit 消费检查，不能将其当作网页动态验证。深色、贴边、全部错误状态、VoiceOver 与真实输入仍须在原生 App 完成。

生成命令（OPC 根目录）：

```bash
python3 ccShot/docs/ui-v3/generate.py --png
```

源文件 [generate.py](ui-v3/generate.py) 复用第二版生成器中的自制图形和 PNG 导出函数，因此保留 `ui-v2/generate.py`；SVG/HTML 可独立打开。PNG 导出使用本机已有 Pillow，不安装新包。用户已认可整体风格，D11 的具体场景仍按实际验收状态，已完成的原生工作以 `app/README.md` 和 HANDOFF 为准。
