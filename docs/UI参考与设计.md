## CcShot 的界面取舍

1. **截图后继续在原位置工作。** 框选后出现浮动工具栏；进入美化才展开专门窗口。CleanShot X 的独立编辑窗口不是 CcShot 每次截图的必经步骤。
2. **样式就地可见。** 九类标注入口完整排列；选择工具后，下一行展示颜色与对应参数。文本用字号、高亮用透明度、序号用起始号、马赛克用颗粒。当前试稿用示例标记演示样式，没有实现真实绘制、撤销或图层编辑。
3. **直接选字保持默认能力。** 选择工具回到文字选择示例；选中高亮、光标与“复制文字”互相对应。动作条位于画面下方，避免遮住正文。网页中的高亮是固定示例，不是 OCR 识别或任意拖选的验收证据。
4. **钉图与 AI 均按需出现。** 钉图展示独立小窗；AI 展示未配置状态和去设置入口，不预填未确认的模型，也不放假回答。
5. **UI 与功能并列验收。** 本轮检查 PC 画板的内容、对齐、图标与文字遮挡；后续仍须在原生 App 检查真实输入、贴边布局、浅深色、错误状态和辅助功能。设计图通过不等于原生体验通过。

本轮试稿参数：系统字体、13–15pt 常用文字、32–34pt 按钮、8–12pt 浮层圆角、中性灰背景、系统蓝当前动作。它们是自有实现值，不是测量出的竞品规格；无需把这些数字或参考说明放进最终产品界面。

## 试稿能操作到哪一层

- 已编写：七画面导航，标注示例的工具/颜色/参数切换，渐变与纯色、画布比例、内边距/圆角/阴影，示例钉图缩放，键盘激活和滑块方向键。
- “复制文字”只在用户点击后尝试复制固定示例；失败时说明剪贴板未获允许，不伪报成功。
- 保存、图片复制、导入、系统权限和 AI 配置等未接入动作在画面内禁用。登录开关只改变试稿外观，不更改 macOS。
- 本轮没有浏览器交互实测：原生浏览器工具返回 **Local browser use is disabled in Work settings**，没有更换控制通道或启动浏览器绕过。上述交互属于已编写、待浏览器验证。
- 原生 `app/` 本轮不改动；正在进行的原生开发及其验证状态以 `app/README.md` 为准。

已核对全部七张 PNG 的完整画面；修复选字操作遮挡正文和导出画布被裁切的问题。SVG 均可解析、资源 ID 不重复，JavaScript 语法检查通过，本地链接齐全。PNG 由 macOS Quick Look 直接渲染同一份 SVG，再裁去导出用的空白区域；不是浏览器页面截图。

源文件是 [generate.py](ui-v2/generate.py)，生成的 SVG、PNG 与 HTML 一起交付。生成命令（OPC 根目录）：

```bash
python3 CcShot/docs/ui-v2/generate.py --png
```

PNG 导出使用 macOS 自带 Quick Look 及本机已有的 Pillow；不带 `--png` 时仅需 Python 标准库生成 SVG 和 HTML。
