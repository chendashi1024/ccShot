| 5 | **AI 用 BYOK（用户自带 Key）** | 我们不提供模型、不部署模型。默认 DeepSeek（便宜）；预设 GPT、Claude、Gemini、通义千问、Kimi、智谱、OpenRouter 等主流厂商；也能自定义 Base URL + Key + 模型名。参考 CC Switch 思路，但做简单：所有 AI 设置在一个设置页。Key 存 macOS 钥匙串。 |

## 2026-11-08 · 审美与识字方向

用户确认按本轮建议先看框选、标注、选字三张连贯设计稿，要求圆润感明显、绿色好看。审美与截图后直接用字为当前核心；采用自动识别、主动复制的交互方向，AI 暂缓。

候选见 [ui-v4](ui-v4/README.md)。30 点圆角、叶绿色标注和具体工具栏布局均为本轮设计提案，待用户反馈；不将“同意先出稿”记录成设计定稿或原生实现验收。

### 2026-11-08 · 完成出口与固定审美（用户已确认）

主按钮统一为“完成”：有选中文字就复制文字，否则复制图片，成功后结束截图；⌘C 使用同一目标规则但不结束。保存输出图片文件，钉住转为桌面浮窗。选字不再弹出复制/全选小面板，两项操作保留在右键菜单；快捷键放到悬停提示，去掉底部常驻说明。

产品主动确定符合审美的默认规则，固定绿色、圆润线端、线宽与开口箭头尖等，不提供颜色/粗细/箭头样式的配置栏，不向用户显示“空心箭头”等实现术语。本轮仅更新设计稿，未修改原生 App；整体方向已认可，具体原生实现仍需验证。

### 2026-11-08 · 恢复精简标注选项（最新要求）

用户要求箭头/画框可选择少量醒目且不刺眼的颜色；主题界面继续为绿色。箭头仅保留直线与曲线，默认曲线，不提供虚线。该决定覆盖此前对箭头/画框“固定绿色且不显示二级菜单”的安排，线宽、圆角等仍由产品预设。

当前 HTML 提案采用珊瑚橙为默认，提供琥珀黄与晴空蓝两个备选；具体色值为设计提案，尚非用户最终定稿。箭头面板为三个色点加直线/曲线，画框仅三个色点。本轮仍只更新设计预览，未修改原生 App。

用户进一步确认：直线/曲线切换用真实箭头样例替代按钮文字，默认选中曲线；名称仅保留在悬停提示和可访问标签中。

### 2026-11-08 · 保存位置自由选择

保存位置不限制为桌面、下载、文稿三个选项。保存窗口显示当前路径与“更改…”入口，正式 App 使用系统文件选择界面浏览有写入权限的任意文件夹；设置页可更改默认保存位置。本次保存的临时改动不覆盖默认位置。

HTML 已展示以上流程，用路径输入模拟文件夹选择，支持取消与空值提示；仅在页面会话内生效，不验证文件夹存在性或权限，不写入实际文件，原生 App 尚未更新。

用户确认按当前交互稿开始原生实施。沿用系统保存窗口，默认 PNG，保留原有 JPG 格式入口。三色和箭头样式在当前编辑窗口内记忆，打开新截图默认珊瑚橙曲线。
