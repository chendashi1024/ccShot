# ccShot · 竞品调研

> 当前基础体验取舍见 [基础截图交互逐项对标](基础截图交互对标.md)（2026-11-03）。下文保留早期定位与价格记录，不作为现行范围：AI、美化已按用户要求后置，DeepSeek 不设当前默认；旧价格与竞品痛点评价不视作本轮重新验证。

> 整理日期：2026-11-03。star 数和状态是讨论时查到的数字，会变化；标「待验证」的是还没再次核对的信息。

## 1. 结论先说

- 「截图 + 选字 + 问 AI」这块功能上的空位已经不大，开源和付费产品里都有人在做。
- **截图美化（加背景、改比例）是标配**：开源同类几乎都有，所以它不是 ccShot 的卖点，只当配套功能。
- ccShot 能赢的地方：**Mac 原生的轻和快 + 开源 + 对中文用户顺手**。具体卖点三个：
  1. 截完文字直接可选（系统 Live Text 同款，像微信截图）；
  2. 一键问 AI，默认 DeepSeek，预填国内主流厂商，用户自带 Key；
  3. 标注样式一眼能调（解决 Snipaste 粗细、样式难找的问题）。

## 2. 直接竞品（截图 + 文字识别 / AI）

| 产品 | 开源 | 平台 / 技术 | 截完选字 | 问 AI | 美化 | 价格 / 备注 |
|---|---|---|---|---|---|---|
| Snipaste | 否 | 跨平台 | 免费版没有 OCR；Pro 版识别后整段进剪贴板，截图直接关掉 | 无 | — | 免费；Pro $19.99。用户在 issue #3610 里要微信式图中选字 |

| eSearch | 是（约 7.4k star） | Electron，非原生 | 框选后 OCR | 可自定义多模态模型接口 | 有 | 免费 |

### Snipaste 的情况

- 优点（要学）：按 F1 立刻唤起截图，F3 钉图，轻和快。
- 痛点（要解决）：免费版没有 OCR；OCR 在 Pro 版里，识别后整段进剪贴板、截图直接关掉，不能像微信那样在图上选字；标注的粗细、样式等选项藏得深，要找半天。
- issue #3610：用户在反馈仓库里明确要求微信式的图中选字。链接：https://github.com/snipaste/feedback/issues/3610

## 5. 美化功能：大家都有

macshot、Capso（含固定 1920×1080）、better-shot、capcap、eSearch、Snapzy 都已经有截图美化，Ta 在做。
**结论**：美化必须有（没有会显得缺功能），但不当卖点。ccShot 做免费基础版（渐变 / 纯色背景、比例预设、阴影圆角内边距、记住预设），参照 OpenScreen 的画面合成面板，在演示 GIF 里作为配套功能出现。

## 6. ccShot 的定位

> 像 Snipaste 一样快和轻的 Mac 截图工具，截完文字直接能选，一键问你自己的 AI（默认 DeepSeek）。开源、免费、原生。

| 对比点 | ccShot 的做法 |
|---|---|
| 和 Snipaste 比 | 保留 F1 秒开；免费就能选字；标注样式一眼可见；多了问 AI |
| 和 PixPin 比 | 开源；问 AI 用自己的 Key，不用会员 |
| 和 eSearch 比 | Mac 原生（不是 Electron），更轻更快 |
| 和 Ta 比 | 更重视基础截图标注体验和中文厂商预设；需要持续关注它的进展 |
| 和 macshot 等开源 CleanShot 替代品比 | 它们主攻全家桶，我们主攻「截完选字 + 问 AI」，并做好中文用户体验 |

| **ccShot（已选）** | GitHub 上只有一个 0 star 的空仓库叫 ccshots；Homebrew 里没有同名；`ccshot.app`、`ccshot.dev`、`ccshot.io` 都还没人注册；`ccshot.com` 已被人买下挂牌出售（开源项目用 .app 或 .dev 足够） |

关于 ccShot 的小顾虑：国内开发圈说 "cc" 常让人想到 Claude Code（如 CC Switch），可能被误会成配套工具；名字本身也看不出功能。决定仍用它，因为 cc 是作者名字缩写、可当个人品牌，而且 CleanShot、Snipaste 这类名字也看不出功能，README 第一句讲清用途即可。
