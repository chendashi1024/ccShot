# 完整交互设计预览

2026-11-08，按用户要求补齐各工具的选中效果与菜单。延续已认可的圆润绿色方向与固定审美，仍未修改原生 App。

## 可以查看和操作

- 审稿导航“查看”：框选、箭头、画框、文字、画笔、遮挡、高亮、序号、选字与右键、钉图、保存、菜单栏、设置、完成。
- 所有绘图工具选中即用，不提供颜色、粗细、字体或箭头形态配置栏。箭头没有二级菜单。
- 查看各工具会载入一个默认样例；在画布中拖动可以实际绘制箭头、框、画笔、遮挡与高亮；点击放置自动序号。第一次绘制替换展示样例，后续绘制可叠加。
- 文字在画面内直接输入，回车确认；撤销支持回退标注，快捷键也支持重做。
- 框选四边控制点可以调整样例外观尺寸；这是排版示意，不是真实屏幕裁剪。
- 选字使用样例 DOM 的实际文字选择，右键显示复制/全选；完成按当前选字状态展示文字或图片输出结果。没有调用 OCR 或系统剪贴板。
- 保存展开名称和位置，默认 PNG；设置只有截图快捷键和默认保存位置。设置值只作用于演示。
- 钉图切换到无边界控制点的图片浮窗，仅留编辑、保存和关闭；完成与取消可回到“再截一张”。

审稿导航、深色开关和画面下的交互说明是预览辅助，不进入正式产品。菜单栏的三个截图入口复用同一自制笔记，未进行真实系统截图。保存、复制、退出是明确的演示结果，不操作系统文件、剪贴板或 App；钉图不创建系统置顶窗口。选字不能证明 OCR、遮挡后的安全识字或原生快捷键已验收。
