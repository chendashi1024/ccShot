## 2. 核心交互合同（建议在 D11 一次确认）

### 2.1 主路径

| 用户目的 | 预期路径与结束态 |
|---|---|
| 复制部分文字 | 唤起 → 确定选区 → 在图中文字上拖选并复制；无需 OCR 开关、登录或 Key。所谓三步是三个任务阶段，实际鼠标/按键次数另记。 |
| 标注截图 | 唤起 → 确定选区 → 直接点箭头/画框/文字等并绘制 → 复制/保存/钉图。同一排始终保留工具与输出，样式入口点击一次展开适用参数。 |
| 复制全部文字 | 编辑态或钉图态按钮/⌘⇧C；只写入安全的当前文字。无文字时提示，不清空原剪贴板。 |
| 问 AI | 完成用户主动配置后，⌘J 打开侧栏。PRD 的“一键回答”和“打开后选择问题”有歧义；D12 决定是否同时发送默认问题，未决定前不能宣传一个键得到回答。 |
| 美化 | B/工具栏 → 上次预设或首次 1920×1080 预览 → 复制/保存/钉图；不丢原标注。 |
| 钉图 | 截图内 F3/⌘T 钉当前图；截图外 F3 钉剪贴板。钉图可直接选字，空格进入标注；同会话保留对象。 |

### 2.2 状态、焦点、Esc 和复制

事件优先级建议为：系统弹窗/输入法候选 → 当前文本输入控件 → 正在进行的手势 → 当前面板 → 当前画布工具 → 截图会话 → 全局快捷键。不能把所有按键挂在一个全局处理函数上。

| 状态 | 鼠标/键盘归属 | Esc | 复制/确认规则 |
|---|---|---|---|
| 待机 | F1 唤起，F3 读取剪贴板 | 不影响其他应用 | 不截获其他应用 ⌘C、单键或输入法 |
| 权限引导 | 可授权、取消、打开设置；不能进入假成功截图 | 关闭引导，不循环弹出 | 不改剪贴板 |
| 正在框选/调整 | 控制点和边框优先；拖选任意方向 | 取消本次拖动，恢复之前选区 | 无有效区域时禁止输出并给出轻提示 |
| 选择工具 | 控制点 → 已画对象 → 可选文字 → 其余空白移动选区 | 先取消当前对象/文字选择；没有选择时按“取消选区、再退出”处理，保留可恢复会话数据 | 有文字选择时 ⌘C 复制文字且保留会话；没有文字选择时 ⌘C 复制合成图并退出截图 |
| 标注绘制 | 手势只归当前工具；文字识别层不接管 | 正在画时取消当前手势；否则回到选择工具 | 空格/回车只在无输入控件、无未提交手势时复制图并退出 |
| 文字标注/输入法 | V/B/C、数字、空格、回车、⌘A 都先归输入控件；候选词优先 | 输入法先关闭候选；之后结束本次输入，按冻结规则保存/取消草稿 | ⌘C 复制输入控件选中文字，不复制截图；回车按文字编辑规则换行 |
| AI 面板 | 输入框按正常文本输入；回车发送只在输入法组合结束后 | 关闭面板并取消该会话请求，忽略迟到结果 | 回答的复制按钮复制回答；⌘C 优先原生文本选择，不触发图像输出 |
| 美化面板 | 控件独占相应按键/滚轮；预览不抢输入 | 关闭面板，保留已选美化参数 | 工具栏输出当前合成结果；不是面板控件截图 |
| 钉图查看 | 拖图、滚轮缩放；字上拖选；空格进标注 | 有文字选择先取消；无选择时只关闭当前钉图 | 复制文字时不关图；复制图片也不默认关钉图 |
| 钉图编辑 | 标注时滚轮调粗细，不同时缩放窗口 | 先取消手势/工具，再退出编辑，最后才关闭钉图 | 输出保留所有已提交标注，源像素不被预览缩放降质 |

补充边界：

- 双击文字用于文字选择，不同时触发“双击选区复制退出”；双击确认只能在无文字/对象命中且无输入焦点的明确背景区域触发。D11 需连同发现性一起确认。
- `⌘A` 在选区建立阶段选当前屏幕；文本控件内全选文字；OCR 选择上下文内如何全选须与系统叠层一致，不能误换到全屏。
- 标注颜色键 1–8、工具键 R/O/A/L/P/T/M/H/N/V、B、美化滑块、滚轮、`[` `]` 不得穿透到其他状态。
- 一次笔画、拖对象、改滑块形成合理的一个撤销事务；输入法组合不逐候选字拆撤销。
- 建议钉图窗口透明度仅改变桌面查看效果，不改变文件/剪贴板像素；图像本身的透明通道另由渲染保留。D11 冻结此区别。
- 任意异步操作绑定 `sessionID + imageRevision + requestID` 或等价身份；裁剪、移选区、遮挡、切图、关窗后，旧 OCR/AI 结果不能覆盖新状态。名称是示意，不要求引入特定架构。
- OCR 未完成、无文字或失败时，仍可标注、复制图、保存、钉图；结果不得抢焦点。多屏变化时应安全恢复或明确取消旧会话。

### 2.3 当前可见内容与脱敏

这是输出和 AI 验收的阻断条件：

1. 复制、保存、AI 的图像来自当前裁剪和已提交标注的合成结果；不含选区外屏幕、工具栏、OCR 选择高亮、未处理源图。
2. 裁剪、马赛克、模糊、不透明覆盖会使原 OCR 缓存失效。被裁掉/遮挡区域的原文不能通过“复制全部”、残留选中文字、AI 附带文字、缩略图或元数据输出。
3. 对遮挡区域禁用对应原始文字输出，或从安全合成图重新识别并过滤。安全文字尚未准备好时，只阻止相应文字输出/发送并提示，不能回退旧缓存；图像输出仍可用。
4. 马赛克/模糊不宣传为不可逆安全脱敏；提供明确的完全不透明实心覆盖用法。验证的是原数据没有旁路泄漏，不保证可见模糊图无法被猜测。
5. AI 压缩发生在合成之后；测试连接不带当前截图、OCR 或剪贴板。日志不记录 Key、Authorization、图片 base64 或用户原文。
6. AI 会话中的已发送内容在用户随后遮挡/裁剪时不能自动继续携带：建议使旧上下文失效并提示开启新会话；不能宣称撤回厂商已接收的数据。关闭面板仅清空本地会话。

## 4. 现代界面方向与视觉验收

### 4.1 方向与参考边界

采用“原位置截图 + 常用标注与输出同排 + 就地样式”。箭头、画框、文字放在最前面，随后是画笔、遮挡、高亮、序号、选择与撤销重做，右侧保留样式和输出；不设额外标注入口或完成步骤。暖白、墨灰、深青绿与中文名称是当前候选；深色与原生材料仍待实测。

第三版起点：40pt 操作区、14–16pt 控件文字、8–12pt 圆角。允许一行容纳常见工具，通过分组和间距保持清楚；不为减少按钮数隐藏常用功能，也不靠缩字压缩空间。样式不藏进设置，必要提示保留，撤销重做在同排并兼容标准快捷键。

参考入口：[CleanShot X 官方功能页](https://cleanshot.com/features)、[Shottr 官网](https://shottr.cc/)。已读公开演示的具体范围、来源与自有取舍见 [UI参考与设计](UI参考与设计.md)；没有购买或安装竞品，不把宣传演示当操作实测，不复制品牌、截图素材或代码。

### 4.2 七类画面交付

| 界面 | 必需设计内容 |
|---|---|
| 框选 | 暗化背景、边框/八控制点、尺寸、放大镜、窗口高亮；权限失败和屏幕变化态。 |
| 标注 | 常用标注在首排直接可见，箭头/画框/文字靠前；样式就地展开，选择与撤销重做可发现，输出不要求先退出标注。 |
| 直接选字 | 默认可选、文字光标、选择高亮；加载、无字、失败和旧结果失效；不额外要求打开 OCR。 |
| 钉图 | 图片为主；悬停或键盘聚焦显示标注/复制/关闭；直接选字与滚轮缩放不各占一个按钮，键盘/菜单替代路径可发现。 |
| 美化 | 背景/比例/三滑块、真实像素显示、预览、图片导入失败；不作为每次截图必经页。 |
| AI | 后续按需侧栏；未配置、发送中/流式、取消、错误、只文字提示、清空；展示发送到哪家服务。 |
| 设置与权限 | 当前仅截图快捷键与保存位置，不显示 AI 占位、OCR 开关或未接入功能。首次必要权限、Fn 提示、拒绝/撤回、热键冲突、目录错误按需要出现。 |

先评审框选、标注、选字、钉图四个关键画面；其余三类在进入相应阶段前补齐，不必先画完整 App 才验证本地路径。

### 4.3 UI 验收

- **UI-01 布局：** 选区贴四边/角、极小区域、小屏和混合缩放时，工具栏自动移到可见区域；不挡必需控制点、不让保存/关闭出屏。AI/美化不挤掉必要动作。
- **UI-02 输入：** 按第 2 节逐状态测试快捷键、Esc、复制、双击、滚轮及中文输入法；每个事件只产生一个预期动作。
- **UI-03 可读性：** 深浅色、中文/英文/长模型名/长路径、系统可用字号设置下核心动作可读；图标有 tooltip、快捷键和可访问名称，焦点/选中/禁用可区分。
- **UI-04 可操作性：** 键盘走通主要路径，VoiceOver 能读关键控件；减少动态效果模式无必需动画。悬停工具也可用键盘发现。
- **UI-05 真实视觉：** 最终 App 的代表截图/短录屏对照已确认设计，分别看整体易用性与控件/边界/对齐。网页模型、设计图不能代替原生运行证据。

**数据集建议（D10 冻结）：** 普通清晰组至少 30 张，中文/英文/混排各至少 10 张，另设困难组（代码、双栏、小字、低对比等）。每图记录唯一 ID、文件哈希、来源/许可、像素/缩放、语言、人工核对的原文与阅读顺序；不得只选容易成功的图。用于调试和最终回归的样本/版本清楚，变更样本不删除旧失败记录。

质量分开报告，不能用一个“OCR 准确率”概括：

| 维度 | 测量方式 | 目标/判断 |
|---|---|---|
| 字符识别 | CER = (替换数 S + 删除数 D + 插入数 I) / 真值字符数 N；按组报告总编辑距离/总 N，同时列单图值。N=0 的图单列。固定 NFC 等规范化规则，并单列空格换行政策 | 建议普通组各语言 CER ≤5%，困难组单列；只是待确认目标。CER 可能超过100%，不截断数字或美化结果。 |
| 整行 | 逐行完全匹配比例；报告缺行、多行、断行 | 报告实测分布，不以平均字符率掩盖漏行；阈值在试测后冻结。 |
| 阅读顺序 | 真值行序/栏序与输出逐项比对，列错序位置 | 在已声明支持的普通版式中无错序；复杂版式的限制明确列出。 |
| 选择命中 | 至少 30 个确定范围用例，含首尾、单字、四字、跨行、标点、正反向；比较预期范围/高亮/剪贴板 | 已正确识别的目标文字，冻结普通交互用例全部精确对应。选择错误不计入 CER 来掩盖。 |
| 复制语义 | 字符边界、Unicode、空格/换行、无字/遮挡时的剪贴板行为 | 保留该范围实际文本，无额外字符/旧缓存；与识别质量和排版顺序分开记录。 |

OCR 引擎真实漏字与选择层多选一字是不同缺陷。可用“识别文本已正确的样本”独立检查选择层，但最终同时报告端到端结果。原型四字拖选通过仅能支持对应单个用例；已交付的32张合成图基准另有CER统计，但8段文本的重复呈现不满足本文建议的真实场景分组覆盖，不能因此推导普通用户准确率、阅读顺序或MVP已通过。详见[原型报告](../prototype/local-ocr/TEST-REPORT.md)。

## 6. 性能、可靠性和发布验收

### 6.1 全部数字仍是目标

| 指标 | 原目标/补充建议 | 测量口径（D10 冻结） |
|---|---|---|
| 热键到遮罩 | 原目标 ≤150ms | 暖态 30 次，从热键事件收到到首个可交互帧；P50/P95/最大值，建议 P95 对照目标。真实按键到事件的系统延迟另记。 |
| 冷启动 | 原目标 ≤1s | 进程未运行至少 10 次，到菜单栏及快捷键可用；首次权限/资源准备与常规冷启动分开。 |
| 待机内存 | 原目标 ≤80MB | 无钉图/会话，稳定后用明确物理内存口径；另测 1/5/10 张钉图及关闭后回落。 |
| 普通 OCR | 原目标 ≤0.5s | 从选区确认到文字可选（不只是识别函数返回）；冻结样本，中/英/混排、冷/暖分组 P50/P95。 |

| B 到美化 | 原流程目标约 1s | 默认画布/本地背景，记录可交互和稳定预览时间，不能只量按键响应。 |
| 多屏 | 原要求位置与清晰度正确 | 目标系统/架构、单屏、多屏、Retina+非Retina、负坐标、缩放/热插拔实测。 |
| 稳定性 | 补充建议：30分钟连续使用、200次截图/关闭 | 记录崩溃、遮罩/任务残留、内存趋势与恢复；S1 的30次循环仅作早期冒烟，不替代最终适用检查。 |

缺设备就写未测试；不把模拟屏、静态图或开发机结果宣称覆盖所有机器。未达目标须提交实测、瓶颈和影响；修改阈值须保留原值及决定记录，不能改数值让报告变绿。
