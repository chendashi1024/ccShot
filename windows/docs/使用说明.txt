ccShot · Windows 版使用说明
=========================

完整解压 ZIP 后运行 ccShot.exe。离线识字模型、.NET 8 桌面运行时和 Visual C++ 运行库均已随包提供。
程序未签名。若 Windows 提示未知发布者，请核对 ZIP 的 SHA-256。
文字识别在本机 CPU 上运行，无需账号、网络或 API Key。

启动与截图
----------
· 启动后自动缩小到托盘（右下角通知区域），没有主窗口。
· 默认快捷键 Ctrl+Alt+X：拖动框选区域。可拖选区内部移动或拖边缘调整，回车或双击确认后进入编辑。
· 托盘图标右键：区域截图 / 当前屏幕 / 选择窗口 / 钉住剪贴板 / 设置 / 退出。双击托盘图标等于区域截图。
· 框选时按 Esc 取消。

编辑窗口
--------
· 选字优先：鼠标停在文字上拖动即可选中，Ctrl+C 复制选中的文字，Ctrl+Shift+C 复制全部文字。
· 标注工具：箭头、方框、椭圆、文字、画笔、遮挡、高亮、序号。点工具后在图上拖动绘制。
· 选中的对象可以拖动、拖角缩放、Delete 删除；Ctrl+Z / Ctrl+Y 撤销重做。
· 颜色和粗细就在工具栏里，点颜色块或拖“粗细”滑块即可。
· 遮挡三选一：实心 / 马赛克 / 模糊。三种效果都会停止复制被遮挡原文，隐藏图像细节请用实心遮挡。
· 输出：复制图片、保存（PNG/JPG）或钉住。钉图上可拖选文字，空白处拖动，滚轮缩放，右键继续编辑。
· Esc 依次：取消文字选择 → 回到选择工具 → 关闭编辑器。

文字识别模型
------------
· 模型放在程序目录的 models/mobile 下（det.onnx、rec.onnx、dict.txt），随包附带的是 PP-OCRv4 轻量版。
· 如果目录缺失或文件损坏，截图、标注、复制和保存仍然可用，只是不能选字；程序会提示恢复方法：
  重新解压安装包，或用 windows/tools/fetch-models.sh 重新下载后放回 models/mobile。
· 不联网、不自动下载任何模型。

已知限制
--------
· 核心截图选字流程已在托管 Windows x64 桌面验证。Windows 11 实机和混合缩放双屏仍待验收。
· 代码类文本里的半角括号可能被识别成全角（），空格由像素空隙补偿，个别情况仍会缺失。
· 混合缩放多屏、显示器热插拔、窗口截图的第三方窗口边界仍需实测。
· 更新时退出 ccShot，把新版解压到新文件夹，运行新版；如需回退可重新打开旧目录中的版本。
· 卸载时退出 ccShot 并删除解压目录。清除个人设置时可另行删除 %APPDATA%\ccShot。
