# ccShot 0.1.3 双平台发布

2026 年 11 月 13 日，Windows 首版合入 `main`，macOS 和 Windows 一起发布为 `v0.1.3`。源码标签指向 `7a1a6198b41a96515c687530ed9fe363559f3ac6`。 [GitHub Release](https://github.com/chendashi1024/ccShot/releases/tag/v0.1.3)

- README 补充 Mac 的 ScreenCaptureKit、VisionKit 与选字层，以及 Windows 的 PP-OCRv4 检测、识别、逐字框还原与本地 CPU 推理。 [识字原理](../README.md#识字原理)
- Mac DMG 为 1,837,406 字节，Windows x64 ZIP 为 84,054,446 字节。两端包来自同一源码提交，Release 提供对应的 SHA-256。Windows ZIP 内含模型和运行库。
- Windows CI、macOS 核心检查和官网 18 项测试通过。用正式 ZIP 在离线 Windows 11 ARM64 虚拟机以 x64 仿真截图、拖选并复制，剪贴板回读 `brown`。 [Windows CI](https://github.com/chendashi1024/ccShot/actions/runs/43252986758)
- 官网首屏与底部均提供两个平台入口。正式首页与提交中的文件逐字节一致，从官网匿名下载的两个包均通过 SHA-256 校验。 [官网](https://ccshot.app/)
