# CcShot 本地试用版

当前包仅适用于 Apple Silicon Mac，构建最低目标 macOS 14；本机 macOS 15.4.1 已测试部分核心流程，安装、升级和实体快捷键尚未验收。它是本地开发包，尚未公开发布。

1. 解压后打开 CcShot。它在顶部菜单栏显示名称。
2. 点菜单栏 CcShot → 区域截图。无权限时按提示进入系统设置的隐私与安全性，添加或允许 CcShot 屏幕录制，然后退出并重新打开。
3. 拖出选区后，直接点箭头、画框、文字、画笔、遮挡、高亮或序号开始编辑。选字时点“选择”，再在图中文字上拖动并按 ⌘C。工具样式自动显示在下方；遮挡默认实心，可切换马赛克或模糊。
4. 点击复制、保存或钉住。保存可选 PNG/JPG；钉图按空格进入标注，右键可保存或调整查看透明度。
5. 默认截图键为 F1 或 Control+Option+S；F1 可能需要配合 Fn。实体全局键尚未验证，可先用菜单入口。设置页可更换截图键及保存位置。

本地识字和编辑不需要网络或 API Key。AI、美化和高级设置未进入本轮。撤销重做与当前会话钉图编辑已接入；关闭后不恢复工程。

该包仅有本地 ad-hoc 签名，未做苹果 Developer ID 公证。如果系统阻止打开，保留提示并由本人决定是否信任；安装及安全提示行为尚未验证，不将本包称为可公开分发的正式版。

包旁的「构建清单.json」记录源代码版本及校验值。已知仍需验证：真实中文输入法候选、多屏1x/2x混合缩放、权限恢复、安装升级，以及磁盘满/外置卷断开时的保存恢复。不要将这些项目当作已经通过。
