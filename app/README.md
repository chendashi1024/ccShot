# CcShot 原生开发底座

最低构建目标 macOS 14、arm64；目前只在 macOS 15.4.1 本机验证。使用已有 Xcode，无第三方依赖；构建生成本地 ad-hoc 签名的 `build/CcShot.app`，不安装到 Applications。

```bash
bash build.sh
open build/CcShot.app
```

菜单栏 CcShot → 区域截图。默认 F1、Control+Option+S 注册为截图键，可在设置重新录入截图键；F3 在当前截图中钉图，否则钉剪贴板；实体全局快捷键仍待验证，不把注册成功视为可用。没有屏幕录制授权时仅提示，不申请或更改权限。
